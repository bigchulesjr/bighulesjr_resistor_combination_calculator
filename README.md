Resistor Combination Calculator

What it does

The Resistor Combination Calculator is a Python program designed to calculate the total resistance of resistors connected in series and parallel.

The user enters the number of resistors and their resistance values in ohms. The program automatically calculates and displays the total resistance for both connections.

How to Run It

1. Install Python 3 on your computer or Android phone.
2. Download or clone this GitHub repository.
3. Open the project folder.
4. Run the following command:

python resistor_combination_calculator.py

Sample Output

================================
  RESISTOR COMBINATION CALCULATOR
================================

Enter number of resistors: 3
Enter resistor 1 value (Ohms): 10
Enter resistor 2 value (Ohms): 20
Enter resistor 3 value (Ohms): 30

========== RESULTS ==========
Series Resistance: 60.00 Ohms
Parallel Resistance: 5.45 Ohms

========== COMPARISON ==========
Series resistance is greater.

Calculation completed successfully!

My Own Twist

I added a comparison feature that automatically compares the total resistance in series and parallel connections and tells the user which one is greater.

I also included input validation to prevent invalid or negative resistance values.
